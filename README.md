# -E-COMMERECE-WEBSITE-footwear-hub-
Footwear Hub is a modern, responsive e‑commerce website for footwear shopping. Users can explore Men, Women, and Children collections, add items to their cart, and checkout securely. Built with HTML, CSS, and JavaScript, it features a black &amp; golden theme and smooth, mobile and desktop‑friendly design.
Features
 Home Page with clean navigation

 Category Pages for Men, Women, and Children

 Cart System to add, remove, and clear items

 Checkout Page with customer form and payment options (Cash/Card)

 Black & golden premium theme

 Responsive design for mobile and desktop
 
 Tech Stack
HTML5 → Structure

CSS3 → Styling (custom black & golden theme)

JavaScript → Cart functionality + checkout logic

How It Works
Browse products by category.

Add items to your bag.

View your cart and proceed to checkout.

Fill in customer details and confirm your order.

Receive a thank‑you message after successful checkout.

Inspiration
This project was built to combine style and simplicity, making online footwear shopping smooth and enjoyable
